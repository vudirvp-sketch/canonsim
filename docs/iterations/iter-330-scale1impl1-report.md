(`leverage_over`/`echo_at_least`/`trait_held`), на которые гейтится
ХОТЯ БЫ одна спецификация любого семейства, читается ОДИН РАЗ в

спросе, ОДИН раз на тик, разделяясь между обходами urgencies и
factions (старая жадная форма платила live_leverage и
crystallized_traits ДВАЖДЫ за бит — по разу на семейство — при
доказуемо равных значениях: между вызовами семейств нет коммитов).
