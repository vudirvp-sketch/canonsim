## A. Что сделано

### A.1 P1a — снимок OCC-атрибуции (член №1, occ_refold 27–29%)

`core/intent.py::occ_breaking_cause` — опциональный
`start_state`: копия проекции в момент постановки интента в
очередь (тот же миг, что штамп `based_on_event_seq`) — обход
платит ОКНО [seq, end), а не префикс [0, seq). Точность:
живая проекция == fold(все события) по закону T2, потому снимок ==
fold(events[:seq], initial) в точности. Ранний возврат при пустом
`attributable` — точный (first_failing над пустым списком всегда
None). Резюме-путь и внешние вызовы — прежний fold (default).

`core/loop.py`: FIFO-таблица `_occ_snapshots[id] -> [копии]`.
**Дефект, найденный инструментом на первой же батарее**: id
автономных интентов ПОВТОРЯЮТСЯ (семейные обходы минтят
`urgency_NNNN` каждый бит — тысячу раз в год); однозначная
таблица голодала (186 из 223 completions без снимка) и первое
accept могло получить ЧУЖОЙ снимок. FIFO-спаривание точное: id-
интенты выходят из очереди в (tick, sub_order, actor, seq)-
порядке = порядке push, k-й accept данного id получает k-ю копию —
свою. Три двери постановки (run_steps первый шаг, _feed_next,
_enqueue_autonomous) и pop в accept-двери (дверевые отказы не
утекают — стадо ~45k на килогоде).

### A.2 P1b — бакеты ранжирования + счётчик новизны (член №2, 10.8%)

`core/knowledge.py`: индекс `_runs` (знавший → ранг → связки
тиков) — итерация `_ranked` ровно в порядке стабильной сортировки
(ранг убыв., связки новые-первее, внутри связи — порядок прихода),
ноль сравнений; корректность стоит на законе writer'а (отказ
регрессии тиков, core/log.py). Счётчик `_novelty[рассказчик][
слушатель]` — число строк рассказчика, чей токен слушатель не
держит; O(1)-ответ насыщенной паре (count==0 → ходки нет —
корректно: исключение источника только сужает множество).
Рождение знающего инициализирует его колонку (поздние знаютели).
Инкрементальные веса через `_rows_by_token` + инвертированный
`_token_holders`.

- R2: поведение локально, канон побайтно тот же (§B.2); INV-1..5
  не тронуты, ЛОГ не тронут, корпус-цена ноль.

  actor_id, seq) — INV-2-закон, не предположение; тест
  эквивалентности — исполнитель фальсификатора на 254+ обходах.

  защита от чужого/битого снимка — собственный from_-чек
  apply_event (громко, не тихо).
- Память: FIFO ограничен глубиной очереди (стадо whole-дрена
  ~8,600 копий × 25 сущностей — тяжеловато, но whole и был
  медленной рукой; segmented — единицы).
