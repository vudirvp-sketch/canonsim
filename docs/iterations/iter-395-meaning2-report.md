## B. Измеренное

Свидетель `tests/test_meaningslice2.py` — ПЯТЬ законов, все зелёные
(seed 42, macro-480 близнец семьи settlement):

1. **ГРАНИЦА МИНТА**: записи знания продажи ложатся РОВНО на
   same_location-свидетелей весов — Марен (рука весов), толпа Малби
   (ближняя дорога), сержант НА ПОСТУ (арифметика ротации 1080
   возвращает его на рыночную стойку). Актёр освобождён — конвенция
   авторства (семья reprice/settle: инициирующей руке не нужен
   свидетель её собственного акта; его знание едет его счетами).
2. **ОТСУТСТВУЮЩИЕ КАРТЫ**: KnowledgeView всего лога держит
   `the_bloom_sold` ровно на свидетелях. Хранительница НИКОГДА не
   узнаёт развязку в полосе — карта переправы исполняема: «знает
   утончение пошлины, никогда причину» — материал ошибочного чтения
   («каждая половина считает другую любимицей гильдии») сохранён
   самой границей. Наследник, управляющий, зимний род, чужак —
   безмолвны. Слух — СВОЯ дверь, не утечка (форма zero-leak на
   полосе миро-контента).
3. **РАСХОЖДЕНИЕ СЧЁТОВ (бумага)**: записи продажи касаются ровно
   четырёх ног — бумага мастера ШЕСТНАДЦАТЬ НЕ ТРОНУТА: продажа
   банкует ФОНД (книга хуторов: 3), никогда не платит бумагу —
   «the count prices trust, never coin» (граница §6.4) исполняема.
   Кошель мастера — не терминал цены (его монеты — собственный минт
   потока the_bloom_nets на пересечениях года): дисциплина сиденья —
   «banked where the tally's notches record it».
4. **РАСХОЖДЕНИЕ СЧЁТОВ (переправа)**: продажа НИКОГДА не пишет
   переправу — связь кусает АРТЕРИЮ (куча тоньше 10→9, весы сыты
   0→1, груз пошлины возвращается — E⇄H), не знание. Монеты
   хранительницы — собственный минт потока на пересечениях.
5. **INV-2**: двойной прогон близнеца байт-в-байт.

**Карты позиций (авторская половина, ANCHOR_REGION §7.2)** — пять
ограниченных карт: сиденье (слово потрачено за стояние долга),
весы (счёт публичен — «weight is weight, shaved is shaved»),
гильдейская казна (долг обслуживаем, процентная арифметика),
переправа (груз возвращается, ошибочное чтение цело), дорога
(ближняя свидетельствует, дальняя безмолвна до слуха). Таблица,
находка, измеренная половина, открытая половина — в §7.2.

**НАХОДКА n=2**: смысл ложится на ПЯТЬ позиций — не на одну
драматическую вершину фракции. Срез-2 ПОДТВЕРЖДАЕТ форму среза-1
на материально ином классе события: принудительный сбор по закону
сезона против добровольной развязки по дисциплине ремесла.
