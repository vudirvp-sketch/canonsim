## A. Что сделано

### A.1 Банк эпохи (`core/rng.py`)

Значение на позиции `k` потока — чистая функция счётчика:

```
U(stream, k) = word(k mod 4) из sha256(f"{key}:{k div 4}")
key = stable_hash(f"{seed}:{stream}")
```

- **O(1) к k-му розыгрышу** — скип времени end-state (H9) больше
  не требует O(k) реплея: прыжок счётчика 10⁶ даёт следующий
  розыгрыш напрямую.
- **Чекпойнт = только счётчики** — никогда внутренности
  генератора; курсор сжался до именованных чисел.
- **Изоляция ветвей структурна**: значение позиции фиксировано
  (seed, stream, k) — добавленный/удалённый розыгрыш не сдвигает
  соседние даже в принципе (при MT это была измеримая связность).
- **Блочная конструкция**: один sha256 на 4 розыгрыша (32 байта →
  4×64-битных слова, big-endian) — естественное продолжение
  стиля stable_hash; блочный memo — производное состояние
  (key, block), пересчитывается на прыжке, не экспортируется.
- **Формы**: `randint(lo,hi) = lo + U mod (hi-lo+1)` (смещение
  modulo ≤ span/2⁶⁴ — ничтожно на любом реальном диапазоне);
  `random() = (U >> 11) / 2⁵³`.
- **Громкий отказ legacy** (`core/cursor.py`): курсор с MT-состояниями
  (`streams`) отказан громко с причиной — тихое продолжение
  невозможно по построению (граница эпохи).
