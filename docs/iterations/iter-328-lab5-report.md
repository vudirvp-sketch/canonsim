## A. Что сделано

### A.1 Инструмент декомпозиции стены в labrunner (закон 8)

`--profile-depths 10,100` — первый сид один раз на глубину под
cProfile; рекорд получает блок `profile`:

- **Сплит по членам** (entry-cumtime по документированной карте):
  `occ_refold` (OCC-перефолд префикса лога — член №1 iter-327),
  `knowledge_rerank` (`_novel_facts` — член №2), `beat_rolls`
  (машина роллов), `decay_walk` (NPC×ось), **производные фолды по
  ВЫЗЫВАТЕЛЮ** (pstats-атрибуция callers, в сессии проверена
  точной: сумма ct по callers == cum): жадный clock-путь
  (`_run_beat`+`_run_macro`) против ленивой двери (`_fold_reads`).
  `rest` = остаток; флаг `members_disjoint` — учётный закон жив.
- **Счётчики ULTIMATE-пака, исполнимые**: E03 (повторные парсы
  `_specs` — urgency и faction — на бит), E04 (вызовы
  live_leverage/echo_scores/crystallized_traits: clock-greedy vs
  door-lazy vs СТАТИЧЕСКИЙ спрос — число entries, гейтящихся на
  `leverage_over`/`echo_at_least`/`trait_held`, читается СОБСТВЕННЫМИ
  парсерами пака, не второй истиной), beats/event.
- **Блок growth**: per-call-отношения shallow→deep для каждой
  ключевой функции (форма iter-327: fold ×9.51).
- **canon_check** — собственный фальсификатор инструмента: профильный
  лог байт-в-байт равен непрофильному прогону той же четвёрки
  (seed, anchor, horizon, protocol) на каждой совпавшей глубине;
  breach = RED и exit 1.
- **Честные ярлыки**: `profiled_wall_seconds` — никогда не
  `cost.wall_seconds`; профилированная стена — артефакт инструмента
  (оверхед cProfile), данные — ДОЛИ и ОТНОШЕНИЯ, не абсолюты.

### A.2 Три закона (tests/test_lab.py)

1. **Canon-neutrality** — профилирование наблюдает, не мутирует:
   профильные байты == непрофильным на совпавшей глубине.
2. **Accounting** — сплит разбиает профильную стену (members + rest ==
   total, флаг disjoint); E03 ≥ 1 парс/бит; каждый фолд-функция
   вычисляется на clock-пути ≥ 1 раза/бит при нулевом спросе
   фикстуры (RED-базлайн P0.5-A — перевернётся намеренно, когда
   ленивость битов приземлится); beats/event измерен.
3. **Growth + honest labels** — двухглубинные per-call-отношения;
   `profiled_wall_seconds` под своим ключом; заметка об артефакте.

### A.3 Решение C-13 записано (строка rng-1, TASKS)

RNG-эпоха (counter-based, Philox/Threefry-форма `U(stream,k) =
H(key,k)`) **одобрена принципиально** — горизонт итогового состояния:
режим, где игрок скипает время над тем же каноническим миром
(политика / градостроительный симулятор — слова владельца), что
именованным потокам RngBank даётся только O(k)-реплеем. Порядок
зафиксирован: сначала byte-identical строки scale-1 (P0.5-A/B/C,
P1a/P1b — эпоха ничего не даёт до них), затем строка rng-1 по
отдельному вызову владельца; цена (смена канонических байтов,
миграция логов, перебазирование T1-оракула) едет строкой
имплементации. До тех пор каждое новое read-поверхность
epoch-совместимо по стоящему индексному закону (B7).

## B. Измерено (датум строки: farstead, seed 7, segmented, 10y+100y)

### B.1 Декомпозиция iter-327 воспроизведена записью

| | 10y | 100y |
|---|---|---|
| occ_refold | 6.6% | **27.3%** |
| knowledge_rerank | 1.9% | **10.8%** |
| beat_rolls | ~36% | 23.4% |
| decay_walk | ~16% | 11.5% |
| rest | 38.0% | 26.3% |
| clock_derived_folds | ~1% | 0.7% |
| door_derived_folds | 0.0% | 0.0% |

Оба квадратичных read-side члена названы и растут с глубиной —
долевой рост occ_refold 6.6→27.3% и knowledge 1.9→10.8% при
константном состоянии (25 сущностей). Доли — от ПРОФИЛИРОВАННОЙ
стены (cProfile надувает дешёвые частые вызовы сильнее дорогих —
потому ярлык «shares only, never wall»; доли iter-327 от
непрофильной стены: 23%/21% — тот же порядок, другой знаменатель,
оба ярлыка честны каждый в своей системе).

### B.2 Growth-отношения (10y→100y, per-call tottime)

| функция | инструмент | iter-327 (in-session) |
|---|---|---|
| `fold` | **×9.67** | ×9.51 |
| `_novel_facts` | **×9.54** | ×9.17 |
| `_ranked` | **×10.4** | ×10.02 |

Воспроизведение в пределах шума — суперлинейная сигнатура обоих
квадратичных членов теперь репродуцируема одной командой:
`python scripts/labrunner.py --years 100 --seeds 7 --protocol
segmented --profile-depths 10,100 --pack content/farstead_pack`.

### B.3 Счётчики пака (стабильны по глубинам)

- **E03 = 2.0 парса/бит** (urgency-парс + faction-парс — второй на
  паке БЕЗ factions-блока всё равно вызывается и возвращается пустым).
- **E04 = 5.01 жадных вызова/бит** (live_leverage ×2, echo ×1,
  traits ×2 — оба места вызова в `_run_beat` + макро-пересечения)
  **против 0 гейтящихся entries** — Q7a-растрата квантифицирована: на
  farstead фолды ранний-возврат (блоков secrets/echo/traits нет),
  ВЫЗОВЫ тем не менее стартуют каждый бит. Дверь ленива
  (door_derived_folds = 0.0%, 0 вызовов) — асимметрия iter-45 жива.
- **beats/event = 8.16** на 100y (9.14 на 10y) — цифра пака «~50»
  закрыта измерением: профиль-зависимая, цитируется по-прогону.

### B.4 Canon-neutrality

**HELD на 100y** — профильный прогон (7.7 MB) байт-в-байт равен
непрофильному прогону основной батареи. Фальсификатор инструмента
зелёный на реальном датуме; exit-код несёт вердикт.

## C. Что НЕ сделано (честно)

- **Фикс стены** (индексы OCC-атрибуции и knowledge) — за гейтом
  runtime-promotion, строка scale-1-имплементации; инструмент теперь
  поставляет её RED-базлайны (E03, E04, доли членов).
- **E02/E31 и остальные батареи ULTIMATE-пака** — следующие строки
  Lab-очереди по порядку самого пака, вызов владельца.
- **rng-1** — записана как PARKED-строка с зафиксированным порядком;
  имплементации нет (правильно: пока нечего скипать — эпоха не даёт
  выгоды).
- «~50 beats/event» пака не «исправлен в паке» — пак вне репо и
  удалён владельцем; цифра заменена в инструментальной записи
  (per-run, honest).

## D. Риски

- R2 local-add: изменены только labrunner + тесты; INV-1..5 не
  тронуты, ЛОГ не тронут, корпус-цена +3 быстрых теста (~4.5 с);
  тестов не удалено и не ослаблено (3 добавлено).
- Доли членов от профильной стены ≠ доли от непрофильной стены
  (оверхед cProfile распределён неравномерно) — ярлык «shares of the
  profiled wall, never wall» стоит в рекорде, disposition и нотах;
  robust-датум — growth-отношения (обе глубины одинаково
  инструментованы).
- Атрибуция callers в pstats проверена точной в сессии (сумма ct по
  callers == cum, diff = 0.0 на live-прогоне); учётный закон
  (members + rest == total) — исполняемый тест.
- Модель сплита (какая функция в какой член) — документированная
  карта в модуле; изменение карты меняет члены, но не canon (карта —
  read-side словарь над pstats, не вторая истина).
