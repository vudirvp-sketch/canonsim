## B. Два пакета — одна история на жанровый контур

**Пакет JOURNEY (seed 42, цепочка iter-278):** 43 события, сказка
25 строк. Одна история несёт ОБА жанровых контура сразу: приключение
(отправка → тягость дороги → цель → изменённое возвращение) и тайну
(скрытый факт → ограниченный путь обнаружения → откровение, меняющее
опции). Это самый сильный свидетель гипотезы W6: одна и та же история
читается под двумя рамками.

**Пакет POLITICS (seed 2, both-fires дорога + переход и squeeze
мастера в одном прогоне):** 103 события, сказка 58 строк. Одна история
несёт весь контур политики: два пожара (крепость + Малби), горе,
просыпающееся на каждом, совет гильдии (запирание лавок), два
wergeld-бдения старых семей, squeeze — бумага 16→18→20 на сгоревшем
рынке, строка переоценки публична. Дифференциальный ответ виден внутри
ОДНОЙ истории: гильдия отвечает экономически, семьи — ритуально.
