## A. Что сделано

### A.1 Ручка `--households`: расширение ростера активного юнита

Материализатор grown одной рукой (scripts/densitypack.py):
`--households H` растит домохозяйства АКТИВНОГО юнита (unit 0) с
трёх шаблонных до H; каждая extra-четвёрка — «hearth-voice»
домохозяйство: 4 взрослых (elder/mate/son/daughter, простой
односложный стем из списка 29 — dun/elm/fenn/…/kale, потолок
H ≤ 32 с громким отказом дальше), резиденты на loc_s0_square
(активная локация якоря — население конуса упражняет бит-механику
по-настоящему), Ashen-зеркальная пара-сеть (elder↔mate 80,
son→elder 70, daughter→mate 75 — семантика домохозяйства как
проекционные данные), и ОДИН talk-пост на взрослого (p=1,
сэмплируемое семейство — ρ-ручка его масштабирует) на внутреннем
2-шаговом кольце расширения: `npc_j → npc_{(j+2) mod N}` — два
чередующихся кольца через домохозяйства (старейшины-и-наследники,
хранительницы-и-дочери), биекция по построению.

Ключевой дизайн-закон: кольцо ВНУТРЕННЕЕ — ни один пост расширения
не целится в шаблонного взрослого, поэтому ручки ОРТОГОНАЛЬНЫ
(talk-links пул и цикл дочерей не тронуты; AP-11 коллизия
невозможна по построению — линт это и проверяет). Расширение не
трогает НИ ОДИН счёт: тёплая материальная сеть остаётся шаблонной
дословно — контролируется измерением (A.3). Аддитивная форма:
H=3 (дефолт) — форма density-1 БАЙТ В БАЙТ (закон идентичности).

### A.5 Следствия на долгосрок (почему это была важнейшая строка)

- **Первый DENSITY-SCALE промоушен в репо**: батарея
  density-конверта теперь LOCAL-SCALE (локализационная рука,
  iter-345/346) + DENSITY-SCALE (рука домохозяйств, iter-347) —
  standing classification TEST_PLAN §9.1 синхронизирована.
- **Именованный адрес оптимизации**: экономика тихих пропусков
  инвертируется при плотности — probes ходят по постам × проекцию
  на каждый бит, и биты растут с населением. Будущая строка
  «id→kind индекс в pack.py» (iter-346 предсказал ×2.9 на холодной
  лестнице) при плотности несёт ×211-член — обоснование выросло.
- **Каскад слухов — сверхлинейный усилитель потока**: 3→6097 на
  ×10.7 населения; знание в обращении растёт с популяцией —
  честный предел для любых заявлений о плотности потока.
- **Дивиденды держатся при плотности**: occ-индекс (плоский),
  ленивые чтения (E03/E04 = 0), next_d100_hit (E-плоский) —
  накопленные оптимизации не деградируют на плотном конусе.

  связывающая рука может сломать байтовый закон изоляции — и это
  будет её собственный честный датум.

  (экспонента 2.04 по пяти глубинам × два семени); горизонтная
  стойкость квадратики уже показала на холодной лестнице
  (iter-346: ×1.0 пер-колл по H).
- Директорная рука (--directors on) на плотном конусе — отдельная
  строка (глобальность директора — семантический вопрос, паркуется
  как наблюдение владельца, iter-346 §A.5).
- Оптимизация skip_probes НЕ начата: строка измерила и назвала
  адрес; право допуска оптимизации — за владельцем (семантика
  спек-фильтра не должна молча измениться).
