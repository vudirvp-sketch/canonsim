## A. Что сделано

### A.1 Пак → закон лаборатории (6 законов, исполняемых)

Пак даёт дисциплину, Stage A требует харнесс. `scripts/labrunner.py`
(новый, ~430 строк) — каждый закон пака стал кодом:

1. **Нет второго рантайма** (пак 03 §2): раннер гонит НАСТОЯЩИЙ
   `Simulator`, читает коммитнутый лог через `core.log.read_log`,
   метрики — производные read-side агрегаты; ни своего лога, ни
   RNG, ни планировщика, ни резолвера (INV-1 неприкосновенен).
2. **Player-absent = нет игрок-авторского ввода** (пак 01 §3/03
   §3): фиксированный объявленный якорь = заявленная позиция игрока
   в паке (изобретений ноль), ОДИН wait на весь горизонт; move к
   якорю только если игрок там не стоит (отклонённый move — шум
   харнесса, не факт мира). Пересечения стреляют внутри wait
   (D-038) — мир живёт, игрок молчит.
3. **Директоры выключены по умолчанию** (форма зонда пака 01 §11):
   E0 изолирует собственную каденц-машину мира от сюжетного
   давления директора (`--directors on` — парная рука).
4. **MINIMAL-профиль наблюдения** (пак 09 §5): identity (seed,
   pack@version, schema_version, commit, python, directors,
   горизонт), horizon (final_tick, year_turns), counts (всего/на
   год/уникальные типы/акторы/autonomous share), mix
   (maintenance/account_flow/gate/action/other), state (projection
   entities + declared), cost (wall, bytes). Без пер-событийной
   телеметрии, без viewer-зависимости — запись выводима из
   (seed, pack, horizon).
5. **Контракт эксперимента** (пак 03 §8, E0-подмножество):
   QUESTION/IDENTITY/ARMS/RUNS/METRICS/DISPOSITION — один JSON под
   gitignored `output/`; назначение ≠ реализация разведены.
6. **T1-двойной прогон** (`--verify-replay`, фальсификатор F1):
   тот же seed → байтово идентичные логи. Закон той же среды;
   кросс-среда — `semantic_diff.py`, не сюда (забор replay-1).

### A.2 Абляция: измеренное, а не унаследованное (важная находка)

`--arm minus:<block>` материализует пак минус один опциональный
блок (закон 68a), **фикспоинт мёртвой лексики**: линт сам называет
мёртвые строки шаблонов — материализатор их срезает и перелинтит
(≤32 проходов). Никаких унаследованных таблиц мёртвых строк —
только измерение. Вердикты для province на горизонте 1y+:

- **CLEAN**: `on_action`, `reflection`, `secrets`, `factions`;
- **LINT-REFUSED**: `urgencies` (закон spine-flaw — якоря хребтов),
  `expectations` (непечатаемый belief-токен), `traits` (trait_held
  требует объявленных beliefs);
- **RUNTIME-REFUSED**: `weather` — **цепочка вооружена МАКРО-часами
  (time.macro), а не своим блоком**: day-1 харнесс balance никогда
  не пересекал каденцию, горизонт Lab — пересекает. Множество пака
  tavern на day-1 НЕ переносится на длинные горизонты — это и есть
  закон «re-measured per pack», пойманный живьём. `crime_watch` —
  KeyError отсутствующего блока (пробел runtime-backstop — записан
  как находка руки, НЕ пропатчен здесь: патч = core-change, не эта
  итерация).

### A.3 E0-бейзлайн ИЗМЕРЕН (первый настоящий прогон лаборатории)

**10y × 4 дым-сида** (7/42/93/125, directors off, якорь
loc_riverroad): 7 862 / 7 861 / 7 865 / 7 863 событий —
**вариация ±2 на 10 лет**; ~100% autonomous (игрок авторит ровно
один wait); T1 byte-identity HELD. Смесь (seed 42):
watch_change 7 201 (91.6%), market_opens 360, fair_opens 120,
status_decayed 41, account_sourced 40, weather_turns 28,
сезонные turns по 10, year_turns 10, world_history 9.
**97.3% — maintenance + account_flow; НОЛЬ эколого-замыкающих
семейств** (рождение/смерть/производство/истощение). Вывод пака
01 §11 («мир тикает; он не воспроизводит собственную
материально-социальную экологию») теперь измеренный по-рановый
закон — и честный канареечный тест в suites.

**100y deep run** (seed 7): 78 212 событий, 45.26 MB лог,
**546 s wall**. Ключевой масштабный датум: 10× горизонта = **83×
времени** (6.6 s → 546 s при 9.94× событий) — супер-линейный рост
нативной работы, ЖИВАЯ демонстрация scale-1 Q5 RED-находки на
масштабе целого прогона: LOCAL-бит платит O(|log|)-фолды, лог
растёт, каждый бит дорожает. Прямая проекция: **1 000y ≈ 90 мин
одним сидом, 10 000y ≈ 15+ часов** — первый масштабный даниум Lab,
вход для Stage J (LOD/рефайнмент), НЕ разрешение на оптимизацию
(для индексов/бюджетов — только gate scale-1).

### A.4 Тесты: 9 законов Stage A (`tests/test_lab.py`, новый)
