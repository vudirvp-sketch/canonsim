## C. Живая форма 27B (первый станционный датум настроенного
## профиля)

- **MTP-древо ЖИВОЕ:** acceptance 0.41–1.00 (основная масса
  0.65–0.95), средняя принятая длина 2.0–3.0 токена — спекулятивная
  пара платит на этой полосе.
- **Скорости по логам сервера:** промпт ~297–389 tok/s (611-токенные
  промпты), генерация ~12.3–13.8 tok/s. Generate p50 3796.5 мс —
  кап прозы 512 токенов при ~13 tok/s; чтение для mode-C живой
  игры: бит 27B стоит ~3.8 с против ~0.4–0.5 с у малых полос.
- **KV 16K при q8_0:** ~476–479 MiB на последовательность (строки
  эвикции prompt-cache — кэш 16-FA-слойной гибридной архитектуры;
  контекст честно рециклился через батарею, ноль ошибок).
- **GBNF penalty на 16K:** −19.6 мс (constrained 1699.8 против
  unconstrained 1719.4 p50) — штрафа нет: ни на полосе, ни на
  глубине.
- **Детерминизм:** greedy/seeded/cacheless ×3 + рестарт
  кросс-жизнь — побайтово идентичны НА 16K — глубочайший контекст
  мини-прогона.

## D. Единственный battery_bug — первопричина названа
## (код-уровень)

Счётчик «PROBE BUG — the substrate must hold» получил первый
ненулевой за пять раундов: s8_scene_close_retirement c5, пин
нарратора `scene:loc_tavern.candles = lit` (tex_0001, «The barkeep
lit fresh candles») — отказ, ступень regen.

Механизм: шлюз сцены в `brief/ledger.py::_establish` —
`target != scene.location_id` → отказ `scene_mismatch` (дисциплина
D-037: сценно-скоуп текстура не протекает мимо смены сцены). Игрок
был в loc_street: туда его УВЁЛ собственный путь движка — c2
`move loc_street` (это и корпусный ожидаемый ответ!), затем c3
no_intent, c4 отклонённый take-oil-lamp — 27B так и не вернул
игрока в таверну.

**Вердикт: субстрат устоял** — отказ ЕСТЬ закон, стреляющий по
устаревшему скоупу; пробел — в дизайне фикстур зонда: корпусные
пины нарратора сцеплены с посылками предыдущих семантических ответов
движка (детерминированы у репо-раннера, где пиннуты ВСЕ ответы; у
СВОБОДНОГО движка расхождение ранних циклов ломает посылку позднего
пина). Дефекта репо нет, KI нет; неточна лишь формулировка счётчика
(дрейфнула ПОСЫЛКА фикстуры, не субстрат). Уточнение на стороне
зонда (сцено-относительные фикстуры либо отдельный статус
premise-drift) — вызов владельца, ничего не пронесено тайком.
Попутный датум: все 4 ответа 27B в s8 грамматически валидны, ноль
совпадений с корпусным референсом — честная форма колонки mismatch
на этой полосе.
