## B. Измеренное

Свидетель `tests/test_meaningslice3.py` — ПЯТЬ законов, все зелёные
(seed 80 — измеренный инстанс семьи winterkin, честный
fail-then-pass прочтения; КОММИТНУТЫЙ ПАК САМ ПРИЗМА, нуль патчей):

1. **СЕЛЕКТИВНОЕ РАЗГЛАШЕНИЕ ДОКАЗАТЕЛЬСТВА**: провал прочтения
   минтит только смутные непрочитанные метки читателю (метки остаются
   метками); успех минтит `the_winter_kin` читателю ОДНОМУ — ключ
   левередж-гейта, единственный держатель до заявки.
2. **ГРАНИЦА МИНТА**: записи заявки ложатся РОВНО на со-присутствующих
   лестницы — хозяйка (цель заявки), наследник (ближняя дорога),
   ЗАЯВИТЕЛЬ ВКЛЮЧЁН (канал told, точность exact). Нарочитый контраст
   с освобождённым актёром продажи §7.2: руке торговли не нужен
   свидетель её акта, рука заявки САМА — запись.
3. **ОТСУТСТВУЮЩИЕ КАРТЫ**: KnowledgeView всего лога держит токен
   ровно на свидетелях — лагерь, поместье, рынок, толпа, дозор,
   гарнизон, чужак безмолвны (слух — своя дверь, не утечка). Токен
   оплакивания НИГДЕ: заявка открывает опцию, имена остаются должны —
   исполнение долга свой бит, не побочный эффект заявки.
4. **МОЛЧАНИЕ БУМАГ**: событие заявки НЕ ПИШЕТ НИЧЕГО (конверсный
   бит — знание и есть суть); эхо пишет ровно ОДНУ ногу родства
   (сторона хозяйки 40→80 — арифметика признания, гейт редкости цел:
   заявка отвечает зарубке поколённой давности, новая зима не
   минтится — сторона заявителя остаётся 40, честное состояние); НОЛЬ
   записей счетов через остаток полосы; floodpaper 20 и бумага 16
   стоят — «зарубка ценит заботу, никогда монету» исполняемо в
   собственный момент заявки.
5. **INV-2**: двойной прогон байт-в-байт.

**Карты позиций (авторская половина, ANCHOR_REGION §7.3)** — пять
ограниченных карт: заявитель (отцовская зима отвечена, своя сторона
