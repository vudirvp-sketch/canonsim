### A.4 Кросс-железный T1 — ПОЛНОЕ БАЙТОВОЕ РАЗЛОЖЕНИЕ (главный результат)

Факт, требовавший объяснения: станционный T1 HELD внутри станции
(77,081,726 × 2), но ≠ сэндбоксному 76,951,399 — дельта 130,327 байт
при том, что событий 130,327. Дельта = РОВНО числу событий. Разбор
на четырёх измеримых парах (2y/100y × whole/segmented — логи из
архива против локальной репродукции этой сессии на env-пине):

| лог | события | дельта файла | закон (строки − 1) |
|---|---|---|---|
| 2y whole | 230 | +230 (183,697 → 183,927) | 231 − 1 = 230 ✓ |
| 2y segmented | 290 | +290 (214,021 → 214,311) | 291 − 1 = 290 ✓ |
| 100y whole | 8,557 | +8,557 (4,696,785 → 4,705,342) | 8,558 − 1 = 8,557 ✓ |
| 100y segmented | 14,210 | +14,210 (8,211,101 → 8,225,311) | 14,211 − 1 = 14,210 ✓ |
| 1000y segmented | 130,327 | +130,327 (арифметика манифеста) | 130,328 − 1 = 130,327 ✓ |

**Механизм назван байтами**: станционный лог = сэндбоксный лог, где
(1) каждая строка заканчивается `\r\n` вместо `\n` — Windows
text-mode перевод newline, +1 байт × каждую из 231/291/8,558/14,211/
130,328 строк (проверено od-дампом: сэндбокс `…}}\n`, станция
`…}}\r\n`, одиночных `\r` нет); (2) шапка станции на 1 байт КОРОЧЕ —
`"python": "3.14.3"` (6 симв.) против `"3.12.14"` (7 симв.).
Итого: дельта = (число строк) − 1, ТОЧНО на всех пяти горизонтах.

**Следствие — контент побайтово идентичен**: после вычищения `\r`
все строки событий идентичны побайтово на всех четырёх парах (единственное
отличие любой пары — строка-шапка, поле python). Md5 ПОТОКА СОБЫТИЙ
(шапка исключена) совпадает кросс-железно на всех четырёх логах:
`3e9505ab697b…` (2y whole), `456069491796…` (2y seg),
`b13f22719868…` (100y whole), `e94a0e259595…` (100y seg).
Санкционированный компаратор — `scripts/semantic_diff.py` (ssi-7/D-229,
TEST_PLAN §1.4): **exit 0 SEMANTICALLY EQUAL ×4**, единственное
игнорируемое различие — python-мета шапки (by design).

**Толкование**: ИНТЕРПРЕТАТОР ВКЛАДЫВАЕТ НОЛЬ БАЙТ КОНТЕНТА. Разрыв
3.12.14 ↔ 3.14.3 (два минорных, два релиза CPython) не изменил ни
одного байта сериализации событий — вся файловая дельта разложена на
платформенный перевод строк и мету окружения в шапке, ровно те два
слоя, которые semantic_diff игнорирует by design (§1.4). Вопрос,
который pin исключал («the same environment only»), закрыт измерением:
байтовая идентичность Т1 — свойство КОНТЕНТА, а не окружения;
переменные окружения — только newline-конвенция платформы + записанная
мета. Эпоха RNG (iter-334, sha256-слой) и весь канонический конвейер
переносимы по железу И интерпретатору на килогодной глубине.

**Производная (арифметика закона, без прогона)**: whole-килогод на
сэндбоксе дал бы 45,083,190 − 82,758 + 1 = **45,000,433 байта**
(окно инструмента 600 с держит его непрогоняемым в песочнице — закон
iter-326; число — предсказание закона CRLF, доступное проверке на
любой будущей станции/CI с Linux-боксом).
