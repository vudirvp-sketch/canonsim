profile + шаблон → ОБЫЧНЫЙ ВАЛИДНЫЙ пак через существующий

exits, flow_glosses; serve_the_meal/pail тоже неймспейсены —
AP-11 клонирует пару (intent, requires) через юниты).

Ручки (§9.1, declared-not-implied):
- `--settlements S` — E и L (E = 1 игрок + 12·S взрослых + 3·S
  групп + 2·S предметов; L = 7·S); **K = 0 по построению** —
  ни одного межюнитного ребра (locality-control базлайн;
  связывающая рука — позже отдельной строкой);
- `--talk-links N` — R: экстра talk-посты на юнит (потоки
  детерминированы; AP-11 «одна цель на NPC-глагол» — потолок
  8, сверх — громкий отказ);
- `--prob-scale X` — ρ: множитель ТОЛЬКО на сэмплируемое
  семейство (p<100 — разговоры, трапезы, рационы, холостой
  benсh); p=100 пересечения (материальный цикл) остаются
  определёнными — закон B6.

Детерминизм чистый: генератор без RNG, та же (ручки, шаблон) →
те же байты (закон скаффолда; проверено тестом). `PROFILE.md`
