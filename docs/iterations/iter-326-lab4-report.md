## A. Что сделано

### A.1 Инструмент replay-cost в labrunner (lab-4, R2 local-add)

Метрики MINIMAL-профиля получили блок стоимости чтения (батарея
04 §12: work / log size / REPLAY COST / state size / MEMORY):
`read_seconds` — стена `read_log`; `fold_seconds` — стена
`initial_projection`+`fold`; `replay_alloc_peak_mb` — пик
Python-аллокаций конвейера чтение+фолд по tracemalloc (честная
метка: аллокации интерпретатора, НИКОГДА не OS RSS; переносимо на
Windows-станцию владельца — модуль `resource` не используется).
`wall_seconds` (симуляция) и прежние поля не тронуты; рекорды
предыдущих итераций совместимы (новые ключи — чистое добавление).

### A.2 Два закона lab-4: `tests/test_lab.py`

- **закон инструмента**: рекорд несёт read/fold/alloc-пик, значения
  числовые и неотрицательные, на ОБОИХ протоколах, непустой лог
  платит реальное время чтение+фолд;
- **закон килогодной арифметики**: step-list — чистая функция
  (years, segment_ticks): 1,000y сегментированный = РОВНО 1,000
  ожиданий каденса; кастомный сегмент = целые + хвост-остаток,
  сумма ТОЧНО горизонту; whole на 1,000y — ОДНО ожидание (форма
  закоммиченных байтов не дрейфует с масштабом). Нулевая цена
  корпуса: закон исполняется без запуска мира.

### A.3 Батарея E1: сегментированная лестница 2y→650y

Farstead, сид 7, square, directors off, годовая сегментация.
Точки: 2, 10, 20, 50, 100, 200, 500, **650** — восемь ступеней.
650y — глубочайшая ступень, влезающая в 600-секундное окно
песочницы (см. C.1: окно измерено честно).

### A.4 Станционный зонд v1 (вне репозитория, Правило 9)

`canonsim_station_horizon_probe_v1.zip` (README_RU + .bat +
station_horizon_probe.py): стадии preflight (система/git/метка
lab-4) → sanity (2y paired + T1 на железе станции, секунды) →
control (100y paired, кросс-железный контроль против iter-325) →
**main: 1,000y paired — whole-рука + segmented-рука + килогодный
REALIZED_DELTA, главный датум E1** → package (рекорды + сырые логи
с md5, summary, zip, автозакрытие папки). Каждая стадия — чекпоинт
в try/except: падение одной не останавливает остальные, zip
собирается всегда; таймаут стадии (4 ч по умолчанию) сам по себе
датум. Самопроверен в песочнице end-to-end (preflight + sanity +
control + package, ~80 с, все артефакты и md5 на месте).

## B. Измерено

### B.1 Кривая стены (сегментированная, сид 7)

```
    100   13234   132.3   7216    72.2    20.70     7.3    4.55    0.01     24.6

    650   81823   125.9  46519    71.6   465.22    46.0   28.85    0.06    153.4
```

Локальные экспоненты wall ~ t^α: 1.00 → 1.05 → 1.20 → 1.34 → 1.59 →
1.68 → **1.81** — монотонное круче́ние. Прогноз t^1.3 из iter-325
(«1000y ≈ минуты») опровергнут измерением: от 650y при α=1.81
килогод ≈ 995 с; честный диапазон по трём якорям — **930–1100 с**
(16–18 мин на CPU песочницы). Кривая событий при этом линейна
(~122–132 событий/год, лёгкий дрейф вниз): суперлинейность —
рост СТОИМОСТИ события, не их числа.

### B.2 Закон плоской жизни (главный датум E1)

Автономная жизнь flat: **~71–72 событий/год от 10y до 650y**
(76.7 → 71.3 → 71.6 — ±1 в пределах дрейфа), 650/651 спанов живы.
Мир farstead при годовой сегментации — устойчивый годовой цикл
без коллапса и без взрыва: 325× диапазон горизонта, нулевой тренд
жизни. Закон отложенной реализации получил килогодный ответ:
сегментированный мир живёт КАЖДЫЙ год — 650 лет подряд.

### B.3 Материальные глаголы строго линейны

sourced = 4.00/год ТОЧНО (400/2000/2600 на 100/500/650y),
consumed ≈ 4.03/год, settled ≈ 8.03/год, decay ≈ 48/год (дрейф
54→44→48). Глаголные законы iter-325 (seed-инвариантность) теперь
измерены и по МАСШТАБУ: линейность точная до 6.5 века.

### B.4 Размер состояния константен

`projection_entities` = 25 на 100/500/650y — состояние мира НЕ
растёт с горизонтом; растёт только ЛОГ. Итоговые счета копятся
линейно (~26.3 ед/год: 2,808 → 13,208 → 17,108; вода на source
1,060 → 6,560) — **неограниченная куча Stage B на 6.5-вековом
масштабе** (ограниченный источник — измеренный фальсификатор,
строка за гейтом). Суперлинейность стены при КОНСТАНТНОМ
состоянии — названный разрыв декомпозиции scale-1 (почему
событие дорожает), не догадка здесь.

### B.5 Replay-cost: чтение доминирует

read ≈ 0.62 с/МБ плоско (0.126/0.2 → 28.85/46.0), fold ≈ бесплатен
(0.055 с на 81,823 события — фолд O(1) на событие), пик аллокаций
≈ 3.34× лога, линеен (0.7/0.2 → 153.4/46.0). Возобновление мира =
O(байтов лога), упирается в парс, не в фолд; состояние не
участвует в цене. Прогноз на 1,000y: лог ~70 МБ, read ~44 с
(×2 с tracemalloc в инструменте), alloc-пик ~230 МБ.
