### B.4 Декомпозиция стены (профиль 10y vs 100y, сид 7, песочница)

Ключевые числа (tottime, per-call):

| функция | вызовов 10y→100y | per-call 10y→100y | рост |
|---|---|---|---|
| `fold.py:119(fold)` — OCC-атрибуция | 254 → 2,495 | 114.7 → 1,090.9 µs | **×9.51** |
| `knowledge.py:292(_novel_facts)` — talk | 3,209 → 3,209 | 37.9 → 347.0 µs | **×9.17** |
| `knowledge.py:138(_ranked)` | 3,209 → 3,209 | 19.0 → 190.7 µs | ×10.02 |
| list.sort (в _ranked) | 3,209 → 3,209 | 35.6 → 306.2 µs | ×8.61 |
| `apply_event` (внутри fold) | ~1.6M → 15.8M | — | ×10 число |

**Механизм 1:** `occ_breaking_cause` (core/intent.py:860) на каждый
OCC-отказ (reason=projection_moved) делает `fold(events[:seq])` —
полный перефолд префикса лога с нуля. Вызовы линейны глубине, цена
вызова O(|log|) — квадрат. На 100y это 15.8M apply_event (13.1 с
cum, 23% стены). **Механизм 2:** `_novel_facts` на каждый talk
переранжирует ВСЮ накопленную knowledge говорящего (5.7 с + 6.4 с
_ranked/sort на 100y, 21% стены). Оба — read-side АТРИБУЦИЯ (L3:
derive, never store), не семантика мира.

**Модель:** `wall(t) = A·t + B·t²` (линейная beat-машина + два
квадратичных члена; калибровка на 100y: квадратичная доля 33%):
- локальная экспонента α(t) = (A+2Bt)/(A+Bt): модель 1.01 → 1.05 →
  1.20 → 1.33 → 1.50 → 1.71 → 1.76 → **1.83**; измерено (iter-326 +
  станция): 1.00 → 1.05 → 1.20 → 1.34 → 1.59 → 1.68 → **1.81** —
  совпадение в пределах 0.08 по всей лестнице;
- прогноз килогода из 100y-разложения: ~821 с (sandbox-эквивалент)
  против измеренных ~1,061 с (884.39 × 1.20) — **модель объясняет
  77.5% килогодной стены**; остаток ~22% — третий (сабквадратичный)
  член и погрешность калибровки, честно записан как остаток, не
  «объяснено»;
- прогноз 10,000y (вершина батареи 04 §12): по измеренной кривой
  ≈ 884 × 10^1.8 ≈ **14–16 часов** на станции — верхняя ступень
  измеренно-закрыта до решения по стене.

Прогноз iter-326 (930–1,100 с) — ДЕРЖИТСЯ: sandbox-эквивалент
станции 1,061 с внутри диапазона.
