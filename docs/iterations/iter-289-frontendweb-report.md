## B. S0-скелет (frontend-1) — что высажено

`frontend/` — React 19 + TypeScript 5.8 + Vite 7 + zod 4, ноль
лишних зависимостей (виртуализация — собственная чистая математика,
никакого UI-кита; CSS одностраничный, «no V5.2 polish in S0»).
Структура по §13 пака (владение границами, имена гибки):

| Модуль | Что доказывает |
|---|---|
| `src/api/gateway/contracts.ts` | зеркала закрытых словарей бэкенда (REJECTIONS/STATUSES/EVENT_TYPES/EXPOSURES + §12.1-маппинг исходов) |
| `src/api/gateway/validators.ts` | zod-схемы со strict-объектами (неизвестный ключ = нарушение контракта) + refine закона «OK без rejection, non-OK с rejection» — зеркало `__post_init__` бэкенда |
| `src/api/gateway/client.ts` | ЕДИНСТВЕННЫЙ транспортный адаптер: POST /op, четыре полосы исхода (DELIVERED-OK / DELIVERED-nonOK / TRANSPORT / MISMATCH), G4 — клиент никогда не ретраит |
| `src/features/gateway-status/` | S0-1: раунд-трип app.status + три честные пробы rejection (DOMAIN_REJECTED / STALE_REVISION / DUPLICATE_REQUEST) — против живого gateway |
| `src/features/trajectory/` | S0-2: LIVE-хвост session.events — чистая оконная математика + VirtualList, семантический курсор (последовательность), выборка по event_id, RESYNC-адаптер перечитывания, LIVE-метка (volatile ≠ durable history), буфер ограничен 50k |
| `src/state/session/useTabSession.ts` | S0-3: пер-таб клиент — свой client_request_id → свой детерминированный session_id; ноль localStorage/sessionStorage/BroadcastChannel |
| `src/app/composition/App.tsx` | единственный композиционный корень + S0-4 инструмент: load probe (реальные session.attach CAS-пары) |
| `tests/fixtures/` | 10 контрактов, снятых с живого кода gateway (in-process dispatch — байтовая форма закона чётности) + манифест провенанса |
| `tests/` | 46 vitest: юнит (математика окон), контракт (валидаторы против живых фикстур + порча отвергается; клиент против мока fetch — все четыре полосы), интеграция (jsdom: 10k+ строк → монтируется только окно; выборка по семантическому id; RESYNC-баннер; DISCONNECTED честно) |

## C. Живые доказательства (8 скриншотов в паке доказательств)

Сессия в headless-браузере против реального gateway (21 операция в
app.status):

1. **S0-1 раунд-трип**: app.status OK — service/contract/exposure/
   operations; сессия создана (SESSION_CREATED в хвосте).
   Скрин 01.
2. **S0-1 честные rejection-пути** (все три против живого gateway,
   отрендерены дословно): `session.get` по фейковому id →
   DELIVERED · REJECTED · DOMAIN_REJECTED; attach с revision 999999 →
   STALE_REVISION; повторный create с тем же ключом, другой материал
   → DUPLICATE_REQUEST. Скрин 02.
3. **S0-4 нагрузка**: 300 реальных session.attach (CAS-петля, 600
   POST-раундтрипов) за 2.48 с = **120.9 ops/s**; UI оставался
   отзывчивым на всём прогоне. Скрин 03.
4. **RESYNC_REQUIRED вживую**: 300 операций при выключенном поллинге
   прокатили 256-event retention; следующий poll честно показал баннер
   и перечитал удерживаемое окно (с seq 346). Скрин 04.
5. **S0-2 виртуализация**: +10 000 синтетических строк (чётко
   помечены SYNTHETIC, презентационные, не правда gateway) →
   10 301 строка данных, **21 смонтированный DOM-узел** (aria-rowcount
   10301). Скрин 05.
6. **S0-3 независимость табов**: таб 1 session `0bb37c82…`, таб 2 —
   `514dda2a…` (свой ключ → своя сессия), третий таб чисто;
   localStorage/sessionStorage пусты, BroadcastChannel не используется.
   Скрины 06/07.
7. **Выборка по семантическому id**: клик по строке → инспектор
   показывает полный JSON события (event_id — идентичность, не индекс
   строки). Скрин 08.
