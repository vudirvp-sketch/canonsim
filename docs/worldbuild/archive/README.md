## Standing law for this directory

Do not re-ingest any pack here for subsequent tasks; do not copy its claims
into owner documents without checking the current repository state; do
not extract its files into the active tree (the zips stay the archive
form); consult them the way the legacy worldbuilding source archive is
consulted — to recover provenance, inspect a disputed passage, or
deliberately re-run old research (`../README.md`). The suite's own
authority statement holds: repository owner documents, runtime code,
tests, event history and decisions remain authoritative — the suite is
an agent navigation and research handoff, never a second truth.
