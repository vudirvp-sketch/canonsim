# World Tests and Evidence

**Status:** active verification surface.

This document owns reusable tests and measured findings. It does not turn a test
result into canon unless the result changes an owner document.

## 1. Stress tests from the source corpus

The original Foundation stress testing explored multiple civilization regimes:

- forest;
- mountains;
- industry;
- necropolis;
- underwater;
- maritime/pirate;
- sky enclaves;
- closed technology cities;
- refuge cities;
- ruin frontiers;
- late-game cosmic frontier.

The key finding was not that every regime is equally complete. It was that the
same foundation can generate different pressures and dependencies without a new
fundamental physics for each region.

A particularly useful counterexample was the pirate regime: it can be compelling
without a special Resonance discipline. That guards against making Resonance the
only explanation for every interesting thing.

## 2. Resonance torture tests

The Resonance work tested:

- teleportation;
- resurrection;
- prophecy;
- mind reading;
- longevity/immortality;
- weather control;
- artificial life;
- artificial minds;
- FTL;
- terraforming;
- time travel;
- duplication.

The durable result is the boundary set in `RESONANCE.md`: no ex nihilo creation,
no new information, no causal bypass, no free scale, no free remote coupling, no
perfect restoration, no perfect identity, stability debt, a growing failure
surface, and no oracle-like knowledge.

## 3. Human tests

### Biography test

Can one person plausibly pass through:

`birth → childhood → training → work → family → money/debt → institutions → conflict → loss → adaptation → aging → death → memory`?

A passing result does not require simulating every year. It requires that the
world's institutions and material conditions can explain the life.

### Humor test

Can people joke using their own shared categories, institutions and vocabulary?

### Heartbreak test

Can a loss alter relationships, resources, status, obligations, memory or future
options rather than merely producing sad prose?

## 4. Genre test

A mature anchor should support the same world state across:

`adventure / mystery / politics / relationship drama / tragedy / comedy / biography`.

A genre succeeds when it emerges from a different reading of the same pressures,
not from switching to another authored world.

## 5. Negative test

Every major capability or institution should answer the relevant subset of:

- Why is it possible?
- Why is it not universal?
- What does it replace?
- What does it make harder?
- Who benefits?
- Who resists?
- Who remembers the transition?
- What happens if it disappears?

## 6. Reader / legibility test

Important events need a path to human perception through one or more of:

`observer / knowledge / artifact / institutional response / environment / chronicle / narrative surface`.

A system can exist autonomously without rendering every internal detail, but a
worldbuilding claim should not be treated as proven human value merely because an
internal variable changed.

## 7. Compression test

Remove an element and ask:

> Which causal contour disappears?

If nothing meaningful changes, the element is a candidate for removal or merger.

## 8. Current repository evidence

The repository's world-2 work provides concrete measurements for the anchor
program:

- a first open reskin demonstrated the universal-core claim without core edits;
- Sarrow Vale's later L2 slices added cultures, factions/history, and calendar /
  seasonal weather as independent content-driven arms;
- the world-2 depth audit found a strong ordinary-verb cross-system effect but a
  concentrated option surface at the measured band;
- the final L2 verdict routed future depth work toward content-side consumers,
  not a new generic depth subsystem.

These results are **evidence about the current implementation**, not proof that
the entire broader world is complete.

## 9. Current open tests

### PARTIALLY CONFIRMED — Anchor causal map (2026-09-20, iter-155)

The full chain is authored once end-to-end over the committed substrate — the
crossing household's ladder (`ANCHOR_REGION.md` §6.1, §9's status): the flood
year followed through place/resource → meso institution → actor choice → event
→ knowledge asymmetry → social response → residue → new option, with no new
worldbuilding document per link. Partial: authored band, not pack-live — the
witness carries the chain at the single-NPC band, and the debt carries no
economy flow (the pack is not economy-armed).

### PARTIALLY CONFIRMED — Meso test (2026-09-20, iter-155)

One meso unit authored: the crossing household — macro pressure (the river's
seasonal rise, the guild's paper) translated into ordinary choices (the
high_water rate, the purse-read bend, the pole-or-road question) with persistent
consequences (the debt standing, the reputation residue, the inherited pole).
Partial: the pack embodies the unit only at the single-NPC band (the spine, the
coerce beat, the shelter law); the household's second hand and the debt's flow
are authored, not implemented.

### PARTIALLY CONFIRMED — Meaning distribution (2026-09-20, iter-155)

The first meaning slice (the high-water double toll, `ANCHOR_REGION.md` §7.1):
the same mechanical event carries four different meanings — household survival,
labor skimmed, the road's misread, the institution's interest — distributed
across positions, not accumulated on one dramatic faction vertex. Partial: the
slice is authored over committed knowledge positions; the distribution is not
yet measured on a live session.

### OPEN — Ancient Network back-propagation

Great Fracture without adding special exceptions for each civilization?

### OPEN — Cultural humor and heartbreak

Do Sarrow Vale's own vocabulary, institutions and history support world-specific
humor and loss rather than generic genre scenes?

## 10. Test result vocabulary

Use:

`CONFIRMED / PARTIALLY CONFIRMED / REJECTED / UNRESOLVED / DEFERRED`.

Do not replace this with numeric scores. The point is to preserve uncertainty
without pretending that a coarse score is more precise than the evidence.
