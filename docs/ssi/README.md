# SOFTWARE SEMANTIC INTEGRITY — ENGINEERING CONTROL PACKAGE v3

## Purpose
This package extends the unified SSI doctrine without replacing its core. The baseline remains unchanged. v3 adds a frontier control layer for semantic types/state, capability and noninterference, local/compositional reasoning, implementation-level verification, deterministic simulation, distributed correctness, runtime/delivery governance, agent context/tool supply-chain control, epistemic provenance, and proof-carrying change.

## Canonical processing rule

`problem-mode → intent → substrate → invariant → risk/reversibility → authority/capability → boundary/topology → state/lifetime → representation/complexity → existing primitive → semantic types/contracts → implementation/effects → static enforcement → compositional proof → semantic/adversarial testing → semantic diff → provenance → runtime evidence → progressive/rollback gate → disposition → durable residue/GC`
