# CREDITS — road_pack (the CC-BY sidecar, PACK_SPEC §9)

The road pack's generic noun stack derives from the **D&D Systems
Reference Document 5.1** (Wizards of the Coast, licensed
**CC-BY-4.0**: https://creativecommons.org/licenses/by/4.0/). The nouns
adapted here are the SRD's generic equipment and creature vocabulary
(the lantern, the cudgel, rope-class gear and their kin) — no SRD proper
nouns, characters, or locations are used; the toponyms (the Ashen) and
all named NPCs (Odo) are original. No Open5e API content is vendored:
the starter-table nouns (REFERENCES.md §13, phase 6) were authored from
the SRD 5.1 reference document directly.

This attribution covers pack DATA only (`entities.json`,
`actions.json`, `rules.json`, `templates.json` in this directory). The
engine (`core/`, `sim/`, `brief/`) is original canonsim code and owns
none of these nouns (INV-3).
